Every logo is outlined (no font needed) and includes its own clear space.

- `baiw-wordmark-*`: the full name on one line, 8:1. The default logo.
- `baiw-tagline-color`, `baiw-tagline-reverse`: the one-line wordmark with the tagline "Building and Using Blockchain and AI Safely" beneath it, 5.3:1.
- `baiw-stacked-*`: the full name on two lines, 2.4:1. For narrow and square spaces.
- `baiw-mark-*`: the short name b[AI]w, 2.7:1. For small spaces.
- `baiw-icon-ink`, `baiw-icon-paper`: the mark on a square ground, for avatars, app icons and favicons.

Suffixes: `-color` has `ink` (#141414) letters and the bracketed AI in `signal` (#9163ff), for pale grounds. `-reverse` has white letters and the same purple, for dark grounds. `-black` is one ink, #141414, and `-white` is one ink, #ffffff; in both the brackets alone mark the AI.
